# Ödeme Takip (PWA)

Aylık gider ve ödeme takip uygulaması. Veriler yalnızca cihazınızın tarayıcısında (yerel depolamada) tutulur; hiçbir sunucuya gönderilmez.

## Canlı site

**https://mergrad.github.io/Odeme-Takip-PWA/**

Yayınlanan site `docs` klasöründeki derlenmiş dosyalardan servis edilir. Kod değişikliğinden sonra siteyi güncellemek için projeyi derleyip `docs` klasörünü güncelleyin.

## Yerelde çalıştırma

```bash
npm install
npm run dev
```

## Yedekleme

Uygulama içinden **Ayarlar → Yedek indir** ile `.txt` yedek dosyası alabilir, **Yedekten geri yükle** ile geri yükleyebilirsiniz.
